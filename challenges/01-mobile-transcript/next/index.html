What changed in this prototype

1. Quota timing: when no free minutes remain, the upload card explains the blocking condition before submission instead of waiting for a failed recording.

2. Desktop width: the Library uses a responsive content container up to 1500px while keeping individual controls readable.

3. Mobile navigation: below 900px the desktop sidebar becomes a persistent bottom navigation with familiar icons, short labels, and a visible active state.

4. Scope: this is a front-end prototype. It does not perform real uploads, transcription, billing, authentication, or API calls.
